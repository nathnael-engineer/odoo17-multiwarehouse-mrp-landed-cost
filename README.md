# Multi-Warehouse Odoo 17 MRP & Landed Cost Platform

Custom Odoo 17 Enterprise add-on suite providing automated freight landed-cost allocation, shop-floor OWL barcode confirmation, and PostgreSQL 15 FIFO indexing.

## Key Outcomes

- **99.2%** cycle-count inventory accuracy across 4 warehouses
- **640ms** consolidated FIFO valuation query (reduced from 18s)
- **11 hrs/week** saved per warehouse supervisor
